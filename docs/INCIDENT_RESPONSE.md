# Incident Response and Exercises

Severity 1 includes unsafe medical guidance, invented numerical values presented as facts,
approved-data integrity compromise, credential exposure, consent/privacy breach, or total
production outage. Stop affected traffic, preserve logs/evidence, rotate exposed secrets,
identify the release/corpus/data versions, and notify the Safety/QA, privacy, data, operations,
and release owners. Do not delete evidence or silently edit approved records.

Exercise at least: credential leak, poisoned Qdrant payload, PostgreSQL corruption, embedding
provider outage, unsafe wording report, feedback privacy request, and bad release rollback.
For each exercise record scenario ID, participants, environment, start/end times, injected
events, detection evidence, decisions, recovery point/time, validation results, unresolved
actions, owners, deadlines, and signed facilitator/release-owner decisions. A tabletop is not
a backup/restore drill; label the exercise type truthfully.
