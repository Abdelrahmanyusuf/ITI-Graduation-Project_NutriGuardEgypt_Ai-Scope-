# NutriGuard Presentation

Open [index.html](index.html) in a browser to start the English graduation presentation.

- Use `ArrowRight`, `ArrowDown`, `PageDown`, or `Space` for the next slide.
- Use `ArrowLeft`, `ArrowUp`, or `PageUp` for the previous slide.
- Press `P` to print or export the deck to PDF.
- Speaker notes are in [SPEAKER_NOTES.md](SPEAKER_NOTES.md).
- The standalone 1920x1080 system architecture is in [nutriguard-architecture.svg](nutriguard-architecture.svg), with an additional Mermaid version in [ARCHITECTURE_DIAGRAM.md](ARCHITECTURE_DIAGRAM.md).

The deck is intentionally self-contained: it uses no external fonts, images, scripts, or network requests.
